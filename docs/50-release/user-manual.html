1はじめに

SiteLive Twin は、現場の状況（重機・作業員・工程・原価・安全）を1つの画面で確認し、遅れへの対策を試算して、承認まで進めるためのシステムです。判断の流れ「見る → 気づく → 原因を探す → 対策を比べる → 決める」を途切れずに行えます。

本書は WebUI サンプル v0.2 の動きに合わせて書いています。サンプルでは現場データをブラウザ内のシミュレーションで作っています。MVP では実データに置き換わるため、画面や操作の一部を改訂します。

ログイン

  1. ブラウザで SiteLive Twin を開きます（URL：（未定：本番 URL））。
  2. 本番では会社のアカウント（Entra ID）でサインインします。サンプルでは、ログイン画面で自分のアカウント（支店長・工事部長・現場所長・工務担当・システム管理者）を選び、「ログイン」を押します。
  3. ロールに応じた最初の画面が開きます。経営層は全社ダッシュボード、所長・工務は現場概要、システム管理者は設定です。

ログアウト

画面右上の利用者アイコンを押し、「ログアウト」を選びます。

4経営層のよく使う操作

4.1 全現場の状況を確認する

  1. 「全社ダッシュボード」を開きます。指標カード、現場マップ、現場ステータス表で、遅れや原価の超過がある現場を確認します。
  2. 気になる現場の行またはマップのピンを押すと、その現場の「現場概要」に移動します（サンプルではA現場のみ）。
  3. 「最新アラート」で、遅れや重機の稼働率低下の発生を確認できます。

4.2 対策を承認・差し戻す

  1. サイドメニューの「承認ワークフロー」を開きます（承認待ちの件数が表示されます）。
  2. 「承認待ち」タブで申請の行を押すと、右側に申請詳細が開きます。
  3. 対策内容、起案者のコメント、判断の根拠（起案時点の SPI・CPI・擁壁工の遅れ・重機稼働率）、試算（完成予測・最終原価見込み・対策費）を確認します。
  4. 必要に応じてコメントを入力し、「承認する」または「差戻す」を押します。差し戻すときはコメント（理由）が必須です。
  5. 承認した対策は、翌稼働日から現場に反映されます。反映後は一覧の「効果」欄で、承認時と現在の SPI を比べられます。
自分が起案した申請には「承認する」「差戻す」が表示されず、「自分が起案した申請は承認・差戻しできません（職務分掌）」と表示されます。もう一方の経営層に承認を依頼してください。一覧では「自分の起案」と表示されます。

4.3 週報を確認する

「レポート」で週を選ぶと、週の指標・工種別進捗・主な出来事・承認された対策が表示されます。「印刷・PDF」で会議資料にできます。

5所長・工務のよく使う操作

5.1 遅れの原因を探す

  1. 「現場概要」で、SPI・CPI・工種別の進捗（計画と実績）とアラートを確認します。
  2. 「ライブツイン」を開くと、3D で重機・作業員・進捗を確認できます。視点（全体・擁壁・土工）を切り替え、「計画比較」の色分けで遅れている部分を確かめます。重機を選ぶと、状態と稼働率が表示されます。
  3. 「4D工程」では、ガントチャートと3Dで計画と実績（予測）のずれを確認します。日付スライダーや再生で日ごとの変化を見られます。
  4. 「重機・稼働」で、直近7日の稼働率と待機・故障の状況を確認します。行を押すとライブツインでその重機を表示します。

5.2 対策を試算して起案する

  1. 「対策シミュレーション」を開き、対策（ダンプの追加、擁壁の施工班の追加、土曜稼働など）を選びます。
  2. 試算結果（完成時期、最終原価見込み、対策費）と、全組み合わせのランキングを見比べます。
  3. 「承認を依頼する（起案）」に件名（60文字以内）と理由を入力し、「起案して承認を依頼する」を押します。
  4. 承認ワークフローの「承認待ち」に申請が追加され、経営層に通知されます。

対策が1つも選ばれていない、または件名が空のときは起案できません。画面に理由が表示されます。

5.3 日報を作成する

  1. 「日報」で「本日の日報を作成」を押します。
  2. 天候・作業員数（1〜200）・作業内容（重機・入退場データから自動入力）・特記事項・KY活動の実施を確認し、必要に応じて直します。
  3. 「提出」を押すと、日報一覧に「提出済」として追加されます。

6システム管理者の操作

6.1 設定を変える

  1. 「設定」で、SPI の注意・危険のしきい値、重機稼働率のしきい値、通知の種類を変更し、「設定を保存」を押します。
  2. 危険のしきい値は注意のしきい値より小さくしてください（そうでないと保存できません）。

6.2 シナリオの変更とリセット（サンプルのみ）

サンプルでは、トップバーの「データ連携」から、シナリオ（遅延・順調・重機故障）の切り替えと、10/21 8:00 へのリセットができます。これはシステム管理者だけが操作できます。リセットすると承認待ちの申請は「取下げ」になります。本番ではこの機能はありません。

6.3 監査ログを確認する

「監査ログ」で、ログイン・起案・承認・差戻し・日報提出・設定変更・リセット・CSV出力などの記録を、ユーザーや操作で絞り込んで確認できます。CSV出力もできます。

6.4 ユーザーと権限を確認する

「ユーザー・権限」で、ユーザーとロール、権限の対応を確認します。本番でのユーザー追加とアクセス権の付与は、社内の申請手続きに従います （未定：申請手続き）。

8よくある質問

質問回答
「承認する」ボタンが出ません承認できるのは経営層だけです。経営層でも、自分が起案した申請は承認できません。また、処理済みの申請やシナリオが異なる申請は操作できません。
差し戻された申請を直して出し直したい差し戻した申請は編集できません。対策シミュレーションから新しく起案してください。
承認したのに現場に反映されていません承認した対策は翌稼働日から反映されます。一覧の「効果」欄に「反映待ち」と表示されている間は、まだ反映前です。
リセットのボタンが押せませんリセットとシナリオの変更はシステム管理者だけができます（サンプルのみの機能です）。
「日報を作成」が出ません日報を作成できるのは現場所長と工務です。
他の現場の詳細が見られませんサンプルではA現場だけがデータ連携しています。他の現場は MVP 以降に順次連携します。
画面が暗い／明るい利用者メニューの「表示テーマを切替」で変えられます。
数字の色の基準を知りたいSPI の注意・危険、重機稼働率の注意のしきい値はシステム管理者が設定しています。設定画面で確認できます。
